# GitHub共同編集練習

複数人でブランチ作成、コミット、プルリクエスト、レビュー、マージを練習するためのサンプルです。

## 練習の流れ

1. 自分用のブランチを作成する
2. `members.md` に自分の名前を追加する
3. `ideas.md` にアイデアを追加する
4. 変更をコミットしてプルリクエストを作成する
5. 他のメンバーがレビューしてマージする

## ブランチ名の例

- `feature/add-member-yuki`
- `feature/add-idea`
- `docs/update-readme`

## コンフリクトの練習

複数人が `shared-message.txt` の同じ行を別々のブランチで変更すると、コンフリクト解消の練習ができます。
